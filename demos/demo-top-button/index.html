AppTopButton

Figma 탑 버튼 컴포넌트입니다.

  • outline : 흰 바탕 + 라인 (기본값)
  • fill : 검정 면
  • shadow : 흰 바탕 + 그림자

  • square : 사각 (기본값)
  • round : 6px 라운드
  • circle : 원형

  • chevron : 꺾쇠 (기본값)
  • arrow : 화살표
  • bar : 맨 위 막대 화살표

  • label : 예: TOP

  • fixed : 화면 고정 (기본값 true)
  • threshold : 노출 시작 스크롤 위치(px), 0 이면 항상 노출 (기본값 200)
  • right / bottom : 고정 위치 (기본값 24)
  • target : 스크롤 대상 선택자 (기본: 레이아웃 콘텐츠 → window)
