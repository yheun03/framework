AppInputNumber

Figma 수량 버튼입니다. AppIconButton + AppInput 으로 구성됩니다.

  • box : A 타입 - 사각 라인 (기본값)
  • circle : B 타입 - 원형 버튼
  • plain : C 타입 - 테두리 없음

v-model: 10

  • xs : 24px
  • sm : 36px (기본값)
  • md : 44px
  • lg : 48px
  • min / max : 최소·최대값 (기본 0 / 무제한)
  • step : 증감 단위 (기본 1) - 키보드 ↑ ↓ 로도 증감
  • precision : 소수점 자리수 (기본 0)
  • label : 상단 라벨
  • hint : 하단 보조 문구
  • state : error / warning / success

정상 범위

확인 필요

  • disabled : 버튼·입력 모두 비활성
  • readonly : 값 표시만 (버튼 비활성)

속성 (Props) 13

AppIconButton(−) + AppInput + AppIconButton(+) 로 구성된 수량 입력입니다.

  • 공통 모든 컴포넌트에서 같은 이름·값
  • 기본값 지정하지 않으면 적용
  • 값을 누르면 속성="값" 이 복사됩니다.
