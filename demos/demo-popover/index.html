AppPopover

Figma 노출 레이어 컴포넌트입니다.

  • #trigger : 레이어를 여는 요소 슬롯
  • default slot : 레이어 내용
  • title : 레이어 제목

  • click : 클릭 시 열고 닫기, 바깥 클릭/ESC 시 닫힘 (기본값)
  • hover : 마우스 오버 시 노출, 레이어 위로 이동해도 유지
정지 (hover)

  • bottom : 아래 (기본값)
  • top / left / right : 위 / 왼쪽 / 오른쪽

  • width : number(px) | string (기본값 320)
  • closable : 닫기 버튼 (기본값 true)

  • v-model:open : boolean

속성 (Props) 8

대상 근처에 정보 레이어를 노출합니다. (딤 없음)

  • 공통 모든 컴포넌트에서 같은 이름·값
  • 기본값 지정하지 않으면 적용
  • 값을 누르면 속성="값" 이 복사됩니다.
