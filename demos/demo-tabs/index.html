이 콘텐츠는 슬롯으로 렌더링됩니다.

액션 영역

탭 안에 버튼을 직접 배치한 예시입니다.

slot 방식 슬롯 콘텐츠입니다.

variant = "group"
variant = "button"
variant = "grid" :columns="6"
variant = "text"
variant = "group" + item.image (오브젝트 조합형)

v-model: all

속성 (Props) 9

탭 목록, 활성 값, 배치와 크기를 확인합니다.

  • 공통 모든 컴포넌트에서 같은 이름·값
  • 기본값 지정하지 않으면 적용
  • 값을 누르면 속성="값" 이 복사됩니다.
