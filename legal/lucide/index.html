프로젝트 운영 기준

  • 아이콘은 components/icons.ts 에 등록한 뒤 import { IconMenu } ..., <IconMenu /> 로 사용합니다.
  • 새 아이콘은 lucide.dev/icons 에서 이름을 찾아 추가합니다.
  • 크기는 font-size, 색상은 color, 선 두께는 --app-icon-stroke-width (기본 2, 큰 아이콘 1.5) 로 조절합니다.
  • Lucide 는 브랜드 로고를 제공하지 않으므로 SNS 아이콘은 같은 규격으로 직접 정의하며, 각 브랜드 가이드라인을 따릅니다.
