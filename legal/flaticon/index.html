Flaticon 이용약관

본 프로젝트에서 사용하는 Flaticon UIcons의 라이선스 준수 기준입니다. 공식 약관을 우선하며, 아이콘 사용 전 최신 약관을 확인합니다.

적용 기준

  • 기준 문서: Flaticon Terms of use
  • 기준 버전: April 2026
  • 공식 약관: https://www.flaticon.com/legal

무료 사용 조건

  • 무료 라이선스는 Flaticon과 저작자 출처 표기를 전제로 사용합니다.
  • 본 페이지에서 Icons by Flaticon 출처를 명시합니다.
  • 출처 표기 없이 사용하려면 Premium 구독 기간 중 다운로드한 콘텐츠를 사용합니다.
  • 편집용으로 표시된 콘텐츠는 상업 활동, 홍보, 마케팅 목적에 사용하지 않습니다.

사용 제한

  • 아이콘 자체가 핵심 상품이 되는 재판매용 인쇄물, 앱, 게임, 템플릿에는 사용하지 않습니다.
  • 아이콘 파일을 별도 파일, 아이콘 세트, 데이터베이스 형태로 재배포하거나 재판매하지 않습니다.
  • 상표, 로고, 보증 표시처럼 오인될 수 있는 방식으로 사용하지 않습니다.
  • AI, 머신러닝, 개인 식별 기술 학습 목적으로 사용하지 않습니다.

프로젝트 운영 기준

  • 아이콘은 @flaticon/flaticon-uicons 패키지의 UIcons만 사용합니다.
  • 컴포넌트 사용 형식은 import { IconMenu } ..., <IconMenu />로 통일합니다.
  • 새 아이콘 추가 시 Flaticon 내 상업적 사용 가능 여부와 출처 표기 필요 여부를 먼저 확인합니다.
  • 약관이 변경되면 본 페이지와 아이콘 사용 정책을 함께 갱신합니다.
